# Mystery Island — The Lost Treasure ✨🏝️

A magical browser puzzle adventure.

## Chapter I
1. Whispering Gate — riddle
2. Firefly Grove — memory matching
3. Moon Bridge — rune sequence
4. Crystal Cave — hidden-star hunt
5. Ancient Vault — final symbol puzzle

## Features
- Animated magical opening
- Five playable puzzle styles
- Coins, stars, hearts and Starfire shards
- Unlockable island map
- Saved progress with localStorage
- Sound effects
- Responsive desktop and mobile design
- No external libraries required

## Latest fixes
- Firefly Grove cards reveal large, bright symbols.
- Ancient Vault now has simple numbered clues and a clear Moon → Star → Key sequence.

Open `index.html` to play locally.
